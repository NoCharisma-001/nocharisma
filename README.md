# No Charisma

Independent Idea Factory website for [nocharisma.com](https://nocharisma.com).

## Local Development

This project uses Next.js and pnpm.

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Production Checks

```bash
pnpm lint
pnpm build
pnpm start
```

## Deployment

The production branch is `main` and the intended host is Vercel. Production metadata, canonical URLs, sitemap and robots output all reference `https://nocharisma.com`.
